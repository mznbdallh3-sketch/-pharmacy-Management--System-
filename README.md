# Pharmacy Management System

A small educational web application made with HTML, CSS, and JavaScript.

## Features
- Add, edit, delete, and search medicines
- Track category, quantity, price, and expiry date
- Show low-stock and expired-medicine statuses
- Save demo inventory in the browser with localStorage
- Responsive design for mobile and desktop

## Run
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a repository named `pharmacy-management-system`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for the published URL to appear in the Pages settings.

This is a student demo only, not a real pharmacy system. Data is saved only in the current browser.
